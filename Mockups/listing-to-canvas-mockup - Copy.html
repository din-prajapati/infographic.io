Listing to Canvas — Architectural Rules

1. The Listing is the single ground truth: Address, price, beds, baths, photo, agent, brand. It outlives the canvas session.

2. There is exactly ONE Generate button: The assistant never generates designs. It extracts fields into the form or modifies active canvas elements.

3. Extraction happens at fill time: Natural language input instantly fills visible form fields with highlight animations, preventing late errors.

4. Canvas is the source of truth after placement: Selecting an element switches the Assistant to Element Edit Mode (0 credits) for rapid typography/style tuning.

5. S5 → S2 Retention Loop (EPIC-KIT-01): Once a listing is filled, generate Open House flyers, WhatsApp stories, and Price Drop graphics with 1-click without re-typing.
